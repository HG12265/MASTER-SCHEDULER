# Feature Modules

This directory contains domain-driven feature modules for Master Scheduler:
- `academic-setup/`: Academic years, terms, slots, break management
- `programmes/`: Programme degrees, semesters, cohorts
- `classes/`: Class sections and student batches
- `subjects/`: Theory & laboratory subject allocations
- `faculty/`: Teacher directory, availability matrix, workload balancing
- `resources/`: Rooms, laboratories, and physical infrastructure
- `scheduler/`: Google OR-Tools CP-SAT constraint configuration and execution
- `timetable/`: Master, class-wise, faculty-wise, and day-wise grid matrix renderers
- `reports/`: Workload audits, contact hour summaries, PDF/Excel generation
